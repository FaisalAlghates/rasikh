# دليل المستخدم (راسخ)

لكل قسم فيديو شرح على صفحته: `/ar/sections/property` و`/ar/sections/office` و`/ar/sections/broker`، وفيديو منفصل لكل ميزة. هذا الدليل مختصر خطوات كل دور.

> راسخ **يكمّل** منصتي إيجار ومُلّاك ولا يحل محلهما، ولا يعالج دفعات الإيجار، ولا يختم أو يقدّم طلبات الرخص باسم مهندس. كل مخرج هندسي **مسودة** حتى يعتمده مهندس مرخّص.

## البدء

1. افتح الصفحة الرئيسية واختر **قسمك**: إدارة الأملاك أو المكتب الهندسي أو الوساطة. الأقسام الثلاثة مجانية الآن، ولكل قسم مساحة عمله وبياناته.
2. اقرأ صفحة القسم وشاهد الفيديو ثم «ابدأ مجاناً».
3. أنشئ حسابك بالبريد الإلكتروني (والجوال برمز تحقق عند التفعيل)، واختر دورك وأدخل اسمك واسم محفظتك أو مكتبك، ووافق على معالجة البيانات.
4. يمكنك إضافة قسم آخر لاحقاً من قائمة الحساب ثم «أنشئ مساحة عمل جديدة» (حتى خمس مساحات).

## مالك العقار أو مدير العمارة (إدارة الأملاك)

| المهمة                | الخطوات                                                                                                                     |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| إضافة عقار ووحدات     | «العقارات والوحدات» ثم اسم العقار والمدينة والحي، ثم أضف الوحدات.                                                           |
| تسجيل عقد             | «أضف عقداً»: رقم عقد إيجار، المستأجر وبريده للدعوة، التواريخ، الإيجار السنوي. تُنشأ جدولة الدفعات تلقائياً.                 |
| تسجيل دفعة            | افتح العقد ثم «سجّل الدفع» عند الاستلام. راسخ يسجّل فقط ولا يحصّل المال.                                                    |
| التنبيهات             | في «نظرة عامة»: المتأخر والقريب والتجديد. يمكن إضافة العقد إلى تقويمك بملف `.ics`.                                          |
| فحص الاستلام والتسليم | «الفحوصات»: اختر العقد وعدد الغرف، أجب عن كل بند والتقط الصور من التطبيق، ثم وقّع. يوقّع المستأجر فيُقفل الفحص ولا يُعدَّل. |
| الصيانة               | «الصيانة»: افتح البلاغ، أسند جهة التنفيذ، ابدأ ثم «تم الإصلاح».                                                             |
| العمائر واتحاد الملاك | «العمارات والجمعيات»: أضف الملاك ونصيبهم، المصاريف بإيصالاتها، عروض الموردين، التصويت، كشف الشهر.                           |
| سجل العقار            | «سجل العقار»: خط زمني بكل ما حدث، وفيه التصاميم المعتمدة التي تربطها بعقارك.                                                |
| الخريطة               | «خريطة المملكة»: عقاراتك على موقعها؛ ضع الدبوس الدقيق من جوالك وأنت في العقار. يظهر البناء بتصميمه المعتمد إن وُجد.         |
| المساعد               | «المساعد»: اسأل عن عقودك ودفعاتك والإجراءات؛ الإجابة موسومة بالذكاء الاصطناعي وتراجعها أنت.                                 |

## المستأجر

بعد دعوة المالك لبريدك: سجّل بالبريد نفسه وفعّل التحقق، فيظهر عقدك. تستطيع رفع إيصال كل دفعة، ورفع بلاغ صيانة بالصور ثم تقييمه وإغلاقه، ومراجعة الفحص والتوقيع عليه مع ملاحظتك.

## الفني أو المورّد

تظهر لك البلاغات المسندة إليك فقط. حدّث الحالة بملاحظة الإصلاح.

## الوسيط العقاري

1. أدخل رخصة فال وتاريخ انتهائها (يُنبّهك راسخ قبل الانتهاء).
2. أضف العملاء المحتملين برقم جوال سعودي وحرّكهم للأمام في مراحل البيع (لا رجوع).
3. حدّد المعاينات وسجّل نتائجها، وأضف عقود الوساطة والملاحظات. السجل موثّق بالوقت ولا يمكن تعديله أو حذفه.
4. استخدم **فاحص الإعلان** قبل النشر: يذكر البيانات الإلزامية الناقصة أو المنتهية.

## مكتب هندسي

1. **سجّل المكتب**: السجل التجاري وتصنيف هيئة المهندسين وتفعيل بلدي والتخصصات والمدن. لا يعتمد المكتب شيئاً حتى يوثّقه فريق راسخ.
2. **أضف مهندسيك** بالبريد؛ يملأ كل مهندس ملفه (رقم العضوية، التخصص، الانتهاء) ويوثّقه الفريق.
3. **استقبل طلب العميل** بوصفه الحر؛ راجع البرنامج الذي قرأه راسخ.
4. **طبّق اشتراطات الأمانة** على القطعة (اشتراطات وزارة البلديات مدمجة) وأكّد الارتفاع من المخطط المعتمد للقطعة ثم اقبل الطلب.
5. **صمّم الخيارات**: يعرض راسخ من ست إلى اثني عشر تصميماً مختلفاً تجتاز فحوص الاشتراطات والكود الآلية، مع جدول كميات. اختر الطراز (نجدي، حديث، سويسري، فخم) ومرّر المؤشر على التصميم لتراه مجسماً.
6. **شارك الخيارات مع العميل** ليختار، ثم **ابدأ التطوير**: عدّل الغرف فتُعاد الفحوص، وأرسل للمراجعة.
7. **راجع المجموعة**: لوحات AR وST وEL وME وFS، والمجسم، والتخصصات (التكلفة والجدول).
8. **الاعتماد**: يعتمد كل مهندس تخصصه فقط، على بصمة المخطط نفسها؛ ثم يصدر رئيس المكتب المجموعة النهائية. اطبعها بزر «اطبع أو احفظ PDF» (A3 أفقي، لوحة في كل ورقة) أو نزّل DXF وIFC.

القيود: ما لم يتحقق منه مهندس من نص الكود المرخّص يبقى «غير مفحوص»؛ لا يوجد ربط مباشر ببلدي أو الأمانات.

## عميل التصميم

أرسل وصف بيتك واختر المكتب، أكّد البرنامج، ثم اختر من الخيارات التي يشاركها المكتب. بعد الإصدار ترى النسخة المعتمدة وسجل الاعتماد، وتضيفها إلى سجل أحد عقاراتك. لا ترى المسودات قيد المراجعة ولا مشاريع الآخرين.

## فريق راسخ (الإدارة)

في `/ar/admin`: الرد على رسائل الموقع وتقييمات الصفحات، وتوثيق المكاتب والمهندسين، وإضافة اشتراطات الأمانات بمصدرها. تُمنح الصلاحية بالـ Admin SDK فقط.

## خصوصيتك

من «الخصوصية» في مساحتك: تصدير بياناتك أو حذف حسابك (بعد إعادة تسجيل الدخول). السياسة والشروط بالعربية والإنجليزية، وهي مسودات بانتظار مراجعة محامٍ.

## مساعدة

مركز المساعدة `/ar/help` فيه أسئلة شائعة قابلة للبحث، ونموذج تواصل `/ar/contact`.
